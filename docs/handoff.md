### 标签与模板的重要区别

使用 main 上的 `examples/ai-code-review.yml` 接入。模板默认拉取 main，不再随发布改动；后台 Variables 可设置 TOOL_REF 与可选 SHA 锁定/回退。发布标签仍不可移动。稳定协议：run.py 无参数、run.py --policy、has_risk 输出、AI_REVIEW_OPTIONS_JSON 白名单非密钥扩展；现有 Secrets 名称保持兼容。v1.2.0 及更早不支持 --policy，不兼容此新入口。main 更新会直接影响所有自动更新的 CI，须限制工具写权限。新增 Secrets 或 Actions/运行环境变动仍可能需要迁移，不能承诺无限兼容。

## 已约定的行为

1. 分支 push 或手动触发；目前没有 PR 专用审查流程。
2. 没有 OpenAI 密钥就跳过，不调用备用模型。
3. OpenAI 新版 Responses API 优先；失败后才调用 Claude 原生 Messages API。
4. 只审查本次 diff，加上被审提交中有限的项目文档/Skill 上下文，不是全项目扫描；新分支/手动运行只覆盖 HEAD 相对第一父提交，报告明确范围。规范问题校验路径、行号、原文，不执行 Skill；文档缺失或超限标明覆盖不完整。
5. 默认只报告、不阻断。业务 CI 顶部可选开启风险失败；需分支保护才能阻止合并，不能撤销已发生 push。
6. 有明确代码风险/规范问题、改进建议或待确认事项均发钉钉；只有明确问题设置 has_risk，建议/待确认不触发风险阻断。不按自然语言判断。机器人 URL 引用 Secret，关键词可在顶部配置，默认 gitea。
7. 不执行提交内代码、工具指令或自动修复，不部署业务应用。
